# PA4 - Recursividad y Grafos: Módulo Inteligente de Orientación dentro del Campus

Repositorio grupal correspondiente a la evaluación **PA4 - Evaluación aplicada sobre recursividad y grafos** (código de curso `30710`), orientada a diseñar y fundamentar un módulo inteligente de orientación dentro del campus que ordene información, analice rutas posibles entre ubicaciones y justifique el recorrido más conveniente según el contexto[cite: 6, 7].

## Objetivo
Proponer una solución técnica clara y fundamentada para un módulo inteligente de orientación dentro del campus mediante la integración de recursividad, ordenamiento recursivo, grafos y aplicaciones básicas de inteligencia artificial, comparando alternativas de recorrido y sustentando la elección según las necesidades del problema[cite: 6, 7].
