# Actividad 1 — Recursividad

## Descripción
Implementación en Java (`PA4/src/main/java/actividad1.java`) que solicita un número entero por consola y calcula su factorial de forma recursiva.

## Funcionamiento
- **Caso base:** Si `n <= 1`, retorna `1` para detener las llamadas recursivas.
- **Llamada recursiva:** En otro caso, retorna `n * factorial(n - 1)`.

## Prueba y evidencia
- **Entrada de prueba:** `5`
- **Salida obtenida:** `Resultado recursivo (5): 120`
